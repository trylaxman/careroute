
# CareRoute 🏥

### Medical Travel, Simplified.

CareRoute is a medical tourism platform prototype designed to connect international patients with healthcare providers in India.

The platform simplifies treatment discovery, hospital comparisons, travel planning, quotations, and bookings through one seamless experience.

## Features

### Patient Experience
- Explore medical treatments and estimated costs
- Discover and compare hospitals and clinics
- Filter by location, accreditation, pricing, and availability
- Build personalized treatment and travel packages
- Submit medical enquiries and request quotations
- Track bookings, payments, documents, and itineraries

### Clinic Portal
- Manage hospital profiles and treatment pricing
- Update availability
- Review patient enquiries
- Send quotations and manage requests

### Admin Dashboard
- Review and approve healthcare providers
- Monitor bookings and enquiries
- Oversee package management and disputes

## Tech Stack

- Next.js 15 (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/careroute.git
cd careroute
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000.

## Prototype Scope

This is a Phase 1 interactive prototype using fictional data and browser-based local storage.

- No production database or authentication
- No real patient information
- No live hospital integrations
- No real payment processing
- Payment and quotation workflows are simulated

## Planned Production Architecture

- NestJS / Node.js backend
- PostgreSQL database
- Secure authentication and role-based access
- Encrypted medical document storage
- Access logging and audit trails
- Stripe-hosted checkout
- Transactional email and SMS notifications

## Vision

Make cross-border healthcare more accessible, transparent, and manageable by bringing treatment, travel, and recovery planning into one trusted platform.
